# Criminal Case Management System (CCMS)

## Project Overview
The **Criminal Case Management System (CCMS)** is a database project designed to manage criminal cases in a police station. It organizes information about FIRs, police officers, criminals, victims, investigations, and court reports.

## Objectives
- Store and manage criminal case records.
- Maintain data accuracy using SQL constraints.
- Perform CRUD operations.
- Establish relationships between database tables.
- Practice advanced SQL queries and operations.

## Database Entities
The database consists of six main tables:

1. **FIR** – Crime reports and incident details.
2. **Officer** – Police officer information.
3. **Criminal** – Criminal profiles and records.
4. **Victim** – Victim details and medical status.
5. **Investigation** – Investigation records, evidence, and witnesses.
6. **CaseReport** – Court dates, verdicts, and case status.

## Features & SQL Concepts
- Database and table creation (DDL).
- Insert, Update, and Delete operations (DML).
- Primary Keys, Foreign Keys, UNIQUE and CHECK constraints.
- Table relationships and cardinalities.
- INNER, LEFT, RIGHT, FULL OUTER, NATURAL and SELF JOINs.
- Nested and correlated queries.
- Aggregate functions (COUNT, SUM, AVG, MIN, MAX).
- GROUP BY and HAVING.
- Set operations (UNION, UNION ALL, INTERSECT, EXCEPT).
- Database Views.
- ON DELETE CASCADE and ON DELETE SET NULL.
- Error handling and constraint testing.

## Technologies Used
- MySQL
- SQL

## Project Scope
The project includes database design, relational schema, realistic sample records, SQL query implementation, and testing of database constraints and relationships.

**Note:** This project focuses on database functionality and does not include a graphical user interface or website.
